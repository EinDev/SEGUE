    Verbinden mit OBS

    Trag die Zugangsdaten oben (Server, Stream-Key) in OBS ein - am besten per "Kopieren"-Button, um Tippfehler zu vermeiden. Am wichtigsten: teste die Verbindung vor dem Event einmal kurz, nicht erst wenn du gleich dran bist.

    OBS Studio
    1. Einstellungen → Stream.
    2. Dienst: Benutzerdefiniert... auswählen.
    3. Server = der Server-Wert oben, Stream-Key = der Stream-Key-Wert oben (auf "Anzeigen" klicken, dann kopieren).
    4. Ausgabe-Reiter: Video-Encoder H.264 (x264 oder ein Hardware-Encoder), Audio-Encoder AAC - beides ist OBS' Standard, hier muss meist nichts geändert werden.
    5. Übernehmen, dann im Hauptfenster auf Streaming starten klicken.

    Andere Software mit generischem RTMP-Push funktioniert genauso - Server und Stream-Key heißen dort oft "URL" bzw. "Key"/"Pfad". Solange sie H.264-Video und AAC-Audio per RTMP senden kann, passt sie.
