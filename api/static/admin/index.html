DJ-Verwaltung

Jede Person, die sich einmal über den DJ-Link anmeldet, taucht hier auf. Erst nach Freischaltung ("bereit") kann sie tatsächlich einspeisen.

Admins

Der primäre Admin (aus der Server-Konfiguration) kann nicht entfernt werden. Jeder Admin kann weitere Personen befördern oder entfernen.

LJ-Setup

Der Operator, der lokal in OBS zwischen den DJs umschaltet ("LJ"), braucht ein eigenes kleines Steuerskript neben seinem OBS - siehe lj-controller/ im Repo für den vollen Hintergrund. Hier gibt's alles fertig für diese Instanz vorbereitet zum Download.

Komplettpaket herunterladen (.zip) Nur OBS-Szene herunterladen (.json)

Das Paket enthält bereits die Szene-Datei - der separate Button ist nur praktisch, wenn schon alles andere installiert ist und nur die Szene neu importiert werden soll (z. B. nach Änderung von ONAIR_MAX_DJS).

Setup-Schritte für den LJ
  1. Voraussetzungen auf dem LJ-Rechner: OBS 28 oder neuer (für obs-websocket, ist ab 28 eingebaut) und Python 3.10+.
  2. Paket entpacken, dann in einem Terminal im entpackten Ordner: pip install -r requirements.txt.
  3. OBS-Szene importieren: OBS → Szenen-Sammlung → Importieren → die mitgelieferte segue-obs-scene.json auswählen. Enthält bereits eine Szene "Live" mit einer Quelle pro DJ-Slot (RTSP, mit den echten Zugangsdaten dieser Instanz) plus einer Standby-Quelle. Das ist ein Best-Effort-Import - OBS' Szene-Dateiformat ist nicht offiziell dokumentiert. Falls der Import nicht sauber klappt, unten die manuellen Schritte nutzen, das Paket enthält auch dafür die volle Anleitung (README.md).
  4. Kritisch, bei jeder der importierten Quellen prüfen: Rechtsklick auf die Quelle → Eigenschaften → "Close file when inactive" MUSS deaktiviert sein. Steht das an, pausiert OBS die Quelle im Hintergrund und jeder Wechsel dorthin verursacht ein sichtbares Ruckeln/Neuverbinden - der gesamte Sinn des Steuerskripts (glitchfreies Umschalten) wäre damit hinfällig. Der Import setzt das zwar bereits korrekt, aber einmal von Hand gegenprüfen kostet zehn Sekunden und erspart eine böse Überraschung am Abend.
  5. obs-websocket aktivieren: Tools → WebSocket-Server-Einstellungen, aktivieren, Passwort setzen (Port bleibt normalerweise 4455).
  6. config.yaml prüfen (liegt im Paket bereits fertig ausgefüllt, bis auf das obs-websocket-Passwort von eben - das dort eintragen).
  7. Starten: python lj_controller.py in einer sichtbaren Konsole laufen lassen, für die gesamte Dauer des Events - dort stehen alle Reconnects/Wechsel im Log, das ist um 3 Uhr nachts die schnellste Fehlerquelle.
